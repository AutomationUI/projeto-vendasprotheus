# INITIALIZE-PROJECT.md: Inicialização de Novo Desenvolvedor/IA

Siga estes passos ao entrar no projeto pela primeira vez:

1. **Dependências**: Execute `npm install` (ou similar) para garantir que o ambiente está pronto.
2. **Ambiente**: Copie `.env.example` para `.env` e configure as chaves necessárias (Supabase, Stripe).
3. **Leitura**: Leia `AI-START.md` e os arquivos em `memories/repo/`.
4. **Verificação**: Execute `npm run build` para garantir que o projeto está em estado íntegro.
5. **Exploração**: Comece explorando `src/App.tsx` para o Frontend e `server.ts` para o Backend.
