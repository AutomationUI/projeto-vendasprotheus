# START-DAY.md: Início do Dia de Trabalho

Rotina sugerida para começar uma nova sessão:

1. **Atualização**: Verifique se há mudanças no repositório.
2. **Memória**: Leia `memories/local/PROJETO_VENDAS_PROTHEUS-REFERENCE.md` para entender onde a última sessão parou.
3. **Checkup**: Execute `npm test` para garantir que nada foi quebrado por mudanças externas.
4. **Foco**: Defina a tarefa prioritária do dia baseada na seção "Próximos Passos" da memória local.
